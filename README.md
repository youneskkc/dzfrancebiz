# دليل الشركات الجزائرية المرتبطة بفرنسا

موقع ثابت يحتفظ بإصدارات مؤرخة للشركات الموجودة في فرنسا ذات الارتباط الجزائري الموثق بدرجة ثقة عالية.

## التعريف التحريري

تُقبل الشركة فقط عندما يثبت مصدر قابل للمراجعة واحد أو أكثر أن شخصاً يحمل الجنسية الجزائرية يملكها أو يديرها، أو أن مؤسسها مهاجر جزائري في فرنسا. لا تُستنتج الجنسية من الاسم أو الصورة أو اللغة أو العنوان.

## بنية البيانات

- `public/data/releases/index.json`: فهرس الإصدارات.
- `public/data/releases/YYYY-MM-DD/release.json`: لقطة كاملة لإصدار محدد، وتبقى الإصدارات القديمة محفوظة.
- `public/app.js`: العرض والبحث والفلاتر.
- `scripts/build.sh`: بناء النسخة المنشورة في `dist/`.
- `.github/workflows/pages.yml`: بناء ونشر GitHub Pages بعد الدمج أو عند التشغيل اليدوي.

## تحديث يدوي لاحقاً

أي تحديث لاحق يجب أن ينشئ إصداراً جديداً، ويحافظ على السابق، ويملأ `changes.added` و`changes.updated` و`changes.retired`. لا تُنشر نتيجة بلا مصدر ورابط وتاريخ تحقق وحالة مراجعة.

## تشغيل محلي

```bash
python3 -m http.server 3000 --bind 0.0.0.0 --directory public
```

## النشر

المشروع يبني الملفات الثابتة إلى `dist/` ثم ينشرها GitHub Pages عبر GitHub Actions. عند استخدام رابط مشروع GitHub Pages، تستخدم الواجهة مسارات نسبية حتى تعمل داخل اسم المستودع.
